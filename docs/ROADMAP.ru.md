## Этап 0 — Боевой запуск (launch-ready) — ПРИОРИТЕТ

Минимум, чтобы игра стала «настоящей»: устойчивой, честно авторизованной и живущей
между перезапусками. Здесь мало работы и максимум эффекта.

1. 🟢 **Включить сохранение прогресса.** Сейчас база в памяти — прогресс сбрасывается
   при перезапуске Render. Нужно завести бесплатную Postgres (Neon/Supabase) и
   прописать `DATABASE_URL` в Render. Код уже всё умеет — только переменная.
   **[нужно от вас]** — создать БД, я подключу и проверю миграции.
2. 🟢 **Верифицированный вход через Telegram.** Убрать `ALLOW_DEV_AUTH`, задать
   `BOT_TOKEN` от @BotFather — тогда игроки авторизуются реальным Telegram-аккаунтом
   (защита от подмены). **[нужно от вас]** — токен бота.
3. 🟡 **Реконнект в идущий бой.** Сейчас разрыв связи = поражение. Добавить
   переподключение к своему матчу в течение N секунд (сервер держит комнату,
   клиент переотправляет `auth`+`resume`). Критично для мобильной сети.
4. 🟢 **Добить недостающий арт**: логотип, иконка приложения, рамки legendary,
   card_back (4 позиции). **[нужно от вас]** — сгенерировать, я залью.
5. 🟢 **Арена по лиге.** Привязать каждую из 12 арен к своей лиге (сейчас одна на всех).
6. 🟡 **Хостинг-твики для Telegram**: перейти на единый origin (сервер сам отдаёт
   клиент — уже умеет), чтобы не зависеть от очереди GitHub Pages; тёплый прогрев
   Render (или платный план от «засыпания»); настроить Menu Button/Mini App URL.
7. 🟢 **Мягкий запуск**: закрытая группа (Мила + 5–10 человек) → сбор фидбэка → правки.

**Итог этапа:** играбельный, устойчивый продукт в Telegram с честным входом и
сохранением прогресса.

## Этап 2 — Социальность и соревнование

1. ✅ **Дружеские бои** (приватная комната по 4-значному коду, без трофеев/наград):
   хост создаёт код и делится им (кнопка share/copy, Telegram-share), гость входит
   по коду; матч гоняет обычный боевой движок, но результат не трогает ладдер и
   экономику. Комната живёт 5 минут. (build-18) Ссылочный deep-link — на потом.
2. 🟢 **Клановые войны** — ✅ (build-21): недельный формат (UTC-неделя, таймстемпный
   ролловер без крона). Участники приносят клану **очки войны** за победы в
   рейтинговых боях; кланы ранжируются живым **военным лидербордом**. На стыке
   недель прошлая финализируется: каждый вкладчик получает награду по своему
   вкладу × тир клана (по итоговому счёту), в ожидании клейма. Экран «⚔️ Война».
   БД: колонки `clans.war` и `users.war_reward`.
3. 🟢 **Турниры** — ✅ (build-20): одиночный турнир на 4 участника (ты + 3 бота),
   сетка на выбывание (полуфиналы → финал). Твои матчи играются вживую, матчи
   ботов авто-резолвятся детерминированной headless-симуляцией; за чемпионство
   💎30, за финал 💎10. Экран «🏆 Турнир» в хабе. **Мультиигрок по коду** (лобби на
   нескольких людей) — на потом (нужен одновременный онлайн).
4. 🟢 **Реплеи** боёв — ✅ (build-19): сервер хранит recording (сид+колоды+уровни+
   конфиг+действия с тиком) последних матчей и детерминированно переигрывает их,
   стримя те же battle-снапшоты вьюеру (кнопка «📺 Реплей» в хабе и на экране
   результата). **Живое наблюдение (spectate)** за чужим идущим боем — на потом
   (подписка зрителя на активный матч). Основа для киберспорта и антивзлома.

## Этап 3 — Монетизация

**[решение]** — выбрать модель. Рекомендация: **Telegram Stars** (нативная валюта
Mini Apps, минимум трения) как основной канал.

1. 🟡 **Магазин гемов за Telegram Stars** (гемы уже есть в профиле, нужен источник).
   Следующий шаг: серверный invoice (Bot API `createInvoiceLink`, валюта XTR) +
   вебхук бота (`pre_checkout_query` / `successful_payment`) с идемпотентным
   начислением. Требует настройки вебхука и живого теста — под gate `BOT_TOKEN`.
2. 🟢 **Магазин (гемы → золото)** — ✅ (build-22): экран «🛒 Магазин», паки золота за
   гемы (сток; бонус к курсу на больших паках), `store.buyGoldPack`. Ускорение
   сундуков за гемы уже было (build-16). `store.grantGems` готов под Stars (п.1).
3. 🔴 **Боевой пропуск (Battle Pass)**: сезонная дорожка наград, free/premium.
4. 🟡 **Косметика**: скины башен, эмоции, рамки карт (арт рамок/эмоций уже есть) —
   монетизация без «pay-to-win», что важно для честного PvP.

Принцип: не продавать силу. Ускорение и косметика — да; прямое усиление в бою — нет.

## Этап 4 — Лайв-опс, баланс и масштаб

1. 🟡 **Аналитика/телеметрия**: воронка (вход→бой→D1/D7 ретеншн), длина боёв,

2. 🟡 **Регулярный баланс**: харнес `balance-harness.mjs` + реальные винрейты →
   ежемесячная подкрутка констант архетипов. Каталог уже data-driven.
3. 🟡 **Анти-абуз**: сервер авторитетен (читы в бою почти невозможны) — добавить
   троттлинг API, лимиты создания аккаунтов, проверку никнеймов.
4. 🔴 **Масштаб**: при росте — вынести сессии/матчи в Redis, горизонтальное
   масштабирование, разделить регионы матчмейкинга.
5. 🟡 **Контент-кадэнс**: 1–2 новые карты/тема в месяц по тем же формулам —
   свежесть без риска для баланса.
