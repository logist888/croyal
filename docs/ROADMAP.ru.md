## Этап 0 — Боевой запуск (launch-ready) — ПРИОРИТЕТ

Минимум, чтобы игра стала «настоящей»: устойчивой, честно авторизованной и живущей
между перезапусками. Здесь мало работы и максимум эффекта.

1. 🟢 **Включить сохранение прогресса.** Сейчас база в памяти — прогресс сбрасывается
   при перезапуске Render. Нужно завести бесплатную Postgres (Neon/Supabase) и
   прописать `DATABASE_URL` в Render. Код уже всё умеет — только переменная.
   **[нужно от вас]** — создать БД, я подключу и проверю миграции.
2. 🟢 **Верифицированный вход через Telegram.** Убрать `ALLOW_DEV_AUTH`, задать
   `BOT_TOKEN` от @BotFather — тогда игроки авторизуются реальным Telegram-аккаунтом
   (защита от подмены). **[нужно от вас]** — токен бота.
3. 🟡 **Реконнект в идущий бой.** Сейчас разрыв связи = поражение. Добавить
   переподключение к своему матчу в течение N секунд (сервер держит комнату,
   клиент переотправляет `auth`+`resume`). Критично для мобильной сети.
4. 🟢 **Добить недостающий арт**: логотип, иконка приложения, рамки legendary,
   card_back (4 позиции). **[нужно от вас]** — сгенерировать, я залью.
5. 🟢 **Арена по лиге.** Привязать каждую из 12 арен к своей лиге (сейчас одна на всех).
6. 🟡 **Хостинг-твики для Telegram**: перейти на единый origin (сервер сам отдаёт
   клиент — уже умеет), чтобы не зависеть от очереди GitHub Pages; тёплый прогрев
   Render (или платный план от «засыпания»); настроить Menu Button/Mini App URL.
7. 🟢 **Мягкий запуск**: закрытая группа (Мила + 5–10 человек) → сбор фидбэка → правки.

**Итог этапа:** играбельный, устойчивый продукт в Telegram с честным входом и
сохранением прогресса.

## Этап 1 — Удержание и прогрессия (retention)

Причины возвращаться каждый день.

1. 🟡 **Сундуки с таймерами открытия** (дерево/серебро/золото/магия/легендарный):
   слот-очередь, таймеры, ускорение за гемы. Арт сундуков уже есть.
2. 🟡 **Ежедневные задания и награды за вход** (сыграть N боёв, победить карту-цель).
3. 🟡 **Сезоны и сброс лиг**: ежемесячный ладдер, награды за пик, «дорожка сезона».
4. 🟡 **Таблицы лидеров**: топ игроков, топ кланов, локальные/глобальные.
5. 🟢 **Push-уведомления** через бота: «сундук открылся», «твой ход в рейде»,
   «сезон заканчивается».

## Этап 4 — Лайв-опс, баланс и масштаб

1. 🟡 **Аналитика/телеметрия**: воронка (вход→бой→D1/D7 ретеншн), длина боёв,
   винрейты карт, точки отвала. Без цифр баланс и экономика вслепую.
2. 🟡 **Регулярный баланс**: харнес `balance-harness.mjs` + реальные винрейты →
   ежемесячная подкрутка констант архетипов. Каталог уже data-driven.
3. 🟡 **Анти-абуз**: сервер авторитетен (читы в бою почти невозможны) — добавить
   троттлинг API, лимиты создания аккаунтов, проверку никнеймов.
4. 🔴 **Масштаб**: при росте — вынести сессии/матчи в Redis, горизонтальное
   масштабирование, разделить регионы матчмейкинга.
5. 🟡 **Контент-кадэнс**: 1–2 новые карты/тема в месяц по тем же формулам —
   свежесть без риска для баланса.
