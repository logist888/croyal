# Tower Clash — Game Design Document (RU)

**Жанр:** реалтайм PvP «tower-rush», коллекционный карточный батлер (MOBA-lite)
**Платформа:** Telegram Mini App (мобайл-фёрст; также десктоп-Telegram и браузер)
**Сессия:** матч 3–4 минуты + долгая мета-прогрессия
**Статус:** играбельный MVP (билды 1–10)
**Версия документа:** 1.0 · 2026-06-28

> **Оригинальный IP.** Игра воспроизводит *механику и структуру* жанра целиком на
> **своих** арте, именах, персонажах и бренде. Чужие ассеты, названия и торговые
> марки не используются. Механика авторским правом не охраняется; подача — наша.

---

## 1. Титул и мета
Tower Clash — быстрый соревновательный карточный батлер, который живёт **внутри
Telegram**: без установки, мгновенный вход, виральность через чаты. Игрок собирает
колоду из 8 карт и бьётся 1×1 в реальном времени 3–4 минуты, чтобы сносить башни и
зарабатывать короны; затем качает карты, поднимается по аренам и ходит в клановые
рейды на боссов.

## 2. Видение и пиллары
**Питч:** «Дуэль в стиле Clash, в которую играешь не выходя из Telegram — быстрые
1×1 на картах, кланы и кооп-рейды на боссов, с оригинальными героями».

**Пиллары:**
1. **Мгновенно и честно.** Открыл из чата — через секунды в бою; авторитетный сервер,
   без pay-to-win в ядре.
2. **Легко начать, сложно освоить.** Простое управление; темп эликсира, контр-пики и
   контроль дорожек дают глубину.
3. **Всегда есть победитель.** Ничьих нет (см. §5).
4. **Социальность по умолчанию.** Личность Telegram, кланы, кооп-боссы, шеринг результата.
5. **Снэкбл-прогрессия.** Короткие бои питают долгую мету коллекции/прокачки.

## 3. Аудитория и платформа
- **Аудитория:** игроки в мобильные стратегии/PvP 16+, активные в Telegram, любят
  кланы/социалку; СНГ + глобал (игра на **EN/RU**).
- **Почему Telegram Mini App:** zero-install → дешёвый трафик из чатов/каналов;
  встроенная личность (без регистрации); виральные петли (поделиться результатом,
  позвать в клан); платежи Telegram Stars; пуши через бота.
- **Ограничения:** только HTTPS; бюджет производительности webview; нужно «нативное»
  ощущение (хаптика, тема, кнопка «назад»).

## 4. Кор-геймплей-луп
```
Сессионный луп:  Бой → короны/итог → ОТКРЫТЬ СУНДУК (золото+карты) → улучшить карту → Бой
Мета-луп:        Подъём по аренам → разблокировка/прокачка карт → доводка колоды
                 → клан и кооп-босс → сезоны/ивенты
```

## 5. Боевая механика
### 5.1 Арена
- Поле **18×30 тайлов**; **река** по центру + **2 моста** (x≈4.5 и 13.5); 2 дорожки.
  Игрок защищает **низ**, соперник — **верх** (клиент всегда рисует твою сторону снизу).
- **Башни (по 3):** 1 «королевская» (HP **2400**) + 2 «принцессы» (HP **1400**).
  Принцессы стреляют автоматически; **король «спит»**, активируется при уроне по нему
  **или** падении своей принцессы.

### 5.2 Эликсир
- Старт **5**, +1 за **2.8 c**, максимум **10**; **×2 в последнюю минуту**.
- Карта стоит эликсир; сервер отклоняет неоплаченные розыгрыши.

### 5.3 Колода, рука, цикл
- **Колода = 8 карт.** В бою рука из **4** + превью **«следующая»**.
- Разыгранная карта уходит в конец очереди, вытягивается следующая — детерминированный
  цикл. У колоды показывается **средняя стоимость эликсира**.

### 5.4 Управление и зоны
- Тап по карте → тап по **валидному тайлу**. Ставить можно только на **свою половину**,
  пока не снесёшь принцессу врага — тогда **открывается эта дорожка** на его половине.
  **Заклинания** — куда угодно.

### 5.5 Бой и ИИ
- Симуляция **20 тиков/с** (снапшоты клиенту **10/с**). Юниты ищут ближайшую цель,
  **идут к мосту** для перехода реки (наземные), бьют по таймеру атаки. Поддержаны
  сплеш, здания (со временем жизни), «только по зданиям» (танки), заклинания (мгновенный AoE).

### 5.6 Условия победы — **БЕЗ НИЧЬИХ**
- **Лимит раунда 4 минуты**, овертайма нет. Счёт = **короны** (снесённые башни, макс 3).
- Снёс **короля** → мгновенная победа. Иначе на таймауте победитель выбирается всегда
  по цепочке: **больше корон → больше урона по башням → кто первым снёс башню → сид-фолбэк.**
  Не вырвал победу к таймауту = **авто-поражение**. Выход/дисконнект = **авто-поражение**.

### 5.7 Боты
- Если живой соперник не найден за ~6 c — подключается **тренировочный бот** (также для
  обучения), чтобы игра была всегда мгновенной.

## 6. Карты
### 6.1 Модель
Поля: `id`, `name`, **type** (troop/spell/building), **rarity**
(common/rare/epic/legendary), **role** (Воин/Стрелок/Танк/Рой/Сплеш/Здание/Заклинание),
стоимость эликсира, статы (HP, урон, скорость атаки, дальность, скорость, цели,
количество, сплеш, время жизни; у заклинаний — радиус + урон).

### 6.2 Стартовый каталог (10, оригинальные дизайны)
| Карта | Тип | Редкость | Роль | Эликсир |
| --- | --- | --- | --- | --- |
| Пехотинец | troop | common | Воин | 3 |
| Лучницы | troop | common | Стрелок | 3 |
| Крысиная стая | troop | common | Рой | 2 |
| Бастион | building | common | Здание | 5 |
| Стрелок | troop | rare | Стрелок | 4 |
| Бомбардир | troop | rare | Сплеш | 4 |

| Мечник | troop | epic | Воин | 4 |
| Метеор | spell | epic | Заклинание | 5 |

### 6.3 Уровни и прокачка
- Уровни карт до **L6**; каждый уровень — **+10%** к статам (`1.1^(уровень−1)`),
  применяется в авторитетной симуляции.
- Стоимость улучшения (дубликаты + золото):

| С уровня | дубликаты | золото |
|---|---|---|
| 1→2 | 2 | 5 |
| 2→3 | 4 | 20 |
| 3→4 | 10 | 50 |
| 4→5 | 20 | 150 |
| 5→6 | 50 | 400 |

- Улучшение даёт **опыт аккаунта** (= новый уровень ×2) → растёт **уровень короля**.

## 7. Прогрессия и экономика
### 7.1 Кубки и арены
- **Кубки:** +30 победа / −30 поражение (не ниже 0); ключ матчмейкинга.
- **8 лиг/арен** по порогам кубков (оригинальные названия):

| Лига | Порог кубков |
|---|---|
| Учебный лагерь | 0 |
| Лесная поляна | 100 |
| Каменный форт | 300 |
| Огненная кузня | 600 |
| Ледяной пик | 1000 |
| Грозовая арена | 1500 |
| Королевская арена | 2200 |
| Лига легенд | 3000 |

### 7.2 Уровень короля
- Опыт — от улучшений карт; кривая `10 × уровень` опыта на уровень; показан в хабе.

### 7.3 Валюты и награды
- **Золото** (прокачка): +50 победа / +10 поражение; из сундуков.
- **Карты** (дубликаты): дроп за бой (победитель 3 / проигравший 1) + сундуки.
- **Кристаллы** (премиум): за Telegram Stars; ускорения и косметика.
- **Боевой сундук:** после каждого матча — открытие с золотом и картами.

## 8. Кланы и кооп
- **Любой создаёт/вступает**; **максимум 20**; **названия на любом языке** (Unicode) —
  намеренный контраст с англ-only никами (§11).
- **Роли:** лидер (кик, передача, роспуск), старейшина (резерв), участник; клан-чат;
  авто-передача лидерства при выходе.
- **Кооп-рейд на босса:** клан бьёт общего босса в реальном времени. **2+ рейдера
  удваивают** HP **и** урон босса (×2). **Учёт урона** по каждому; награды зависят от
  сложности. (Босс: база HP 12000, урон 120, рейд 3 минуты, до 20 участников.)

## 9. Монетизация (честная by design)
- **Telegram Stars** → кристаллы → косметика, ускорение сундуков, боевой пропуск.
  Соревновательная сила достижима бесплатно; жёсткий pay-to-win исключаем. Покупка
  экономит **время**, а не даёт сырое преимущество при равных вложениях.

## 10. Онбординг и ретеншн
- Экраны согласия (cookies) и возраста («не влияет на геймплей»); авто-вход; **обучающий
  бой** с тренером перед открытием мультиплеера.
- Дейли-награда/таймер бесплатного сундука; задания/достижения; **сезоны** с ресетом
  ранга и боевым пропуском; ивенты; пуши-реактивация через бота.

## 11. Идентичность и аккаунты
- **Auth:** Telegram `initData` (в проде HMAC-проверка ботом; тест-режим доверяет без
  проверки для локалки).
- **Ники — навсегда и только английские:** выбираются **один раз** при регистрации с
  явным предупреждением «навсегда»; правило `^[A-Za-z0-9_]{3,16}$`; **без эмодзи / не-ASCII**;
  неизменяемы на уровне API/БД. (Названия кланов — наоборот, любой язык.)
- **Профиль:** кубки, W/L, золото, кристаллы, опыт/уровень, колода, инвентарь карт, клан.

## 13. Интеграция с Telegram
- **Single-origin:** один HTTPS-URL отдаёт клиент + REST + WebSocket (`wss://host/ws`).
- **SDK:** `WebApp.ready()/expand()`, тема, **HapticFeedback**, MainButton/BackButton.
- **Дистрибуция:** кнопка-меню бота открывает приложение; шеринг результата/инвайты в
  чаты; диплинки на вступление в клан и реванш.
- **Платежи:** **Telegram Stars** (кристаллы/боевой пропуск).
- **Ограничения:** HTTPS обязателен; лёгкий бандл/CPU; цель 60 fps в webview.

## 14. Техническая архитектура
- **Монорепо (TypeScript):** `shared` (типы, константы, каталог карт, валидация,
  протокол — единый источник правды), `server` (Express REST + `ws`, авторитетная
  симуляция, матчмейкинг, хранилище), `client` (Phaser 3 + Vite).
- **Авторитетность и детерминизм:** клиент шлёт только **намерения**; сервер валидирует
  эликсир/зону/кулдаун и рассылает снапшоты. Сид-RNG → воспроизводимость (тай-брейк без
  ничьих, будущие реплеи).
- **Хранилище:** in-memory сейчас (zero-dep) за узким интерфейсом; прод-путь —
  **PostgreSQL** (юзеры, кланы, инвентарь) + **Redis** (очередь матчмейкинга, состояние
  матчей/рейдов, сессии).
- **Хостинг:** Docker / `render.yaml`; `npm start` собирает клиент + поднимает single-origin сервер.
- **Анти-чит:** сервер — единственный источник правды; инварианты (неизменяемый ник,
  лимит клана 20) на уровне store; уровни карт считаются на сервере.

## 15. Арт и аудио
- **Направление:** цельный мультяшно-фэнтези стиль, насыщенный, с жирными контурами;
  **оригинальные персонажи**.
- **Пайплайн:** сырьё в `art/incoming/<категория>/`; `npm run slice` стандартизирует/режет
  (в т.ч. спрайт-листы) в `client/public/assets/` + манифест; игра берёт реальный арт при
  наличии, иначе заглушки-фигуры.
- **Готово:** портреты карт (10), часть боевых спрайтов, лого. **Бэклог:** башни, босс,
  пустая арена, полный набор юнитов, SFX/музыка.

## 16. Контент и баланс
- Сейчас 10 карт; ключевые константы — в `shared/src/constants.ts` и `cards.ts` (единый
  источник правды для клиента и сервера). Философия тюнинга: каждый архетип имеет ясный
  контр-пик; средняя стоимость колоды и темп эликсира — основной рычаг баланса.

## 17. Лайв-опс
- Дейли/бесплатный сундук по таймеру; задания и достижения; **сезоны** с ранкед-ресетами
  и **боевым пропуском**; лимитированные ивенты и режимы; **клан-войны** и лидерборды;
  реактивация пушами через бота.

## 18. Аналитика и KPI
- **Acquisition:** конверсия «чат→игра», K-фактор инвайтов.
- **Engagement:** D1/D7/D30, DAU/MAU, сессий/день, длина сессии, **доля доигранных
  матчей**, время ожидания матча.
- **Monetization:** конверсия в платящих, ARPDAU, выручка Stars.
- **Health:** стабильность тика, доля дисконнектов/форфейтов, распределение длины матчей.

## 19. Юридическое / IP
- Полностью **оригинальные** арт/имена/бренд; никаких чужих ассетов/торговых марок —
  только механика жанра (не охраняется авторским правом). Рекомендация: для публичного
  релиза держать название/лого заведомо непохожими на лидеров жанра.

## 20. Роадмап (по билдам)
- **Готово (b1–b10):** авторитетный 1×1, правила без ничьих, кланы + кооп-босс,
  неизменяемые ники, локализация EN/RU, хаб + лиги + короны + редкость, коллекция +
  уровни + улучшение карт, боевые сундуки, single-origin Telegram-хостинг.
- **Дальше:** Фаза 3 **онбординг** (согласие/возраст + обучающий бой); Фаза 4 **полировка
  боя** (уровни на башнях, эмоции, зум камеры). Затем PostgreSQL/Redis, платежи Stars,
  сезоны/боевой пропуск, полный арт/аудио, клан-войны.

## 21. Риски и митигации
| Риск | Митигация |
| --- | --- |
| Сходство IP с лидером жанра | Оригинальные арт/имена/бренд; юр-пометка; отдельная айдентика |
| Производительность webview на слабых телефонах | Лёгкий бандл, интерполяция снапшотов, бюджет ассетов |
| Реалтайм-нетокод/читы | Авторитетный сервер, только намерения, валидация |
| Холодный старт матчмейкинга | Бот-фолбэк; очередь по диапазону кубков |
| Лимиты/политика Telegram | Следовать гайдлайнам Mini App + Stars; HTTPS single-origin |

## Приложение A — ключевые константы
- Арена 18×30; река y=15; мосты x=[4.5,13.5]. Тик 20/с; снапшот 10/с.
- Раунд 240 c; ×2 эликсир последние 60 c; эликсир старт 5, +1/2.8 c, макс 10.
- Король 2400 HP; принцесса 1400 HP. Короны макс 3.
- Босс: 180 c, база HP 12000, урон 120, кооп ×2, до 20 рейдеров.
- Кубки ±30; золото +50/+10; дроп карт 3/1; макс уровень карты 6 (+10%/ур).

## Приложение B — формулы
- Эликсир/сек = `(удвоение ? 2 : 1) / 2.8`.
- Множитель уровня карты = `1.1^(уровень−1)`.
- Улучшение: дубликаты `[2,4,10,20,50]`, золото `[5,20,50,150,400]`, опыт `= новый_уровень×2`.
- Уровень короля: накопительный опыт, `10×уровень` на уровень.
- Тай-брейк: короны → урон по башням → время первого сноса → чётность сида.
