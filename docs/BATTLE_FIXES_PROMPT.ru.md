# Промпт: изменения боя (фикс установки карт + паритет с оригиналом)

## Контекст / проблема
В бою карты не ставятся на поле. Причины (по коду):
1. Установка реализована как «тап по карте → тап по полю» (два касания), а не
   перетаскиванием. Перетаскивание (`drag`) не вызывает `onclick` карты → карта не
   выбирается → тап по полю ничего не деплоит.
2. На телефоне в Telegram вертикальный жест перетаскивания перехватывается
   Telegram (свайп сворачивает мини-апп): вызываются только `ready()`/`expand()`,
   нет `disableVerticalSwipes()`; у арены нет `touch-action`, касание уходит в
   прокрутку WebView, а не в Phaser.
3. Нет ghost-превью и подсветки зоны: сервер валидирует зону
   (`simulation.canDeployAt`), но клиент не показывает фидбэк — невалидный деплой
   молча игнорируется.

Цель: сделать установку карт и интерфейс боя как в оригинале (см. референс-скрины).

## A. Установка карт (КРИТИЧНО — это и есть баг)
- **A1. Drag-and-drop.** `pointerdown` на карте в руке начинает перетаскивание;
  во время `pointermove` над ареной показывать ghost-превью юнита под точкой
  (портрет/силуэт + имя + «ур. N», как «Лучницы ур. 3» на референсе) и клетку
  установки; `pointerup` в валидной зоне = деплой (отправить `deploy` с тайлом),
  вне зоны/над рукой = отмена (эликсир не тратится). Тап-тап оставить как запасной
  путь для десктопа.
- **A2. Telegram WebApp.** В `initTelegram()` вызвать `WebApp.disableVerticalSwipes()`
  (метод из Bot API 7.7 — обернуть в try/проверку наличия) вместе с
  `ready()`/`expand()`. Это и есть главный фикс перехвата свайпа.
- **A3. Жесты/CSS.** `.arena-host` и canvas → `touch-action: none;`; `body`/`#app`
  → `overscroll-behavior: none;`; в пределах арены глушить прокрутку
  (`preventDefault` на `touchmove`). Убедиться, что canvas сверху по z-index и над
  ним нет невидимых оверлеев, перехватывающих ввод.
- **A4. Phaser-ввод.** Для drag использовать `pointerdown/pointermove/pointerup`
  (не `click`); координаты → тайлы через существующий `toTile`, учитывать `flip`
  стороны.

## B. Зоны установки (зеркалить сервер)
Сервер уже валидирует (`simulation.canDeployAt`): в пределах поля; только своя
половина; на чужую половину — только в линии, где разрушена вражеская
princess-башня; заклинания — куда угодно. Клиент должен это зеркалить:
- во время перетаскивания подсвечивать валидную зону (зелёным) и невалидную
  (затемнение/красный);
- войска/здания — только разрешённая зона; заклинания (meteor, volley) — вся
  арена; реку и клетки под башнями не разрешать (мосты — только путь движения);
- добавить общий хелпер валидации зоны (в `shared`), чтобы клиент и сервер
  использовали одну логику.

## C. Интерфейс боя как в оригинале (по скринам)
- **C1.** Верхняя панель: аватар соперника + ник + «Не в клане»/название клана +
  🏆 кубки; таймер в рамке справа «Осталось M:SS» (×2 в конце).
- **C2.** Башни: 2 принцессы (1400 HP) + король (2400 HP) с каждой стороны;
  полоса HP с иконкой короны и числом над башней; король стреляет только после
  падения принцессы или попадания по нему.
- **C3.** Короны/счёт: при разрушении башни — большая корона на её месте;
  индикатор счёта корон («Ты»: король + 2 башни иконками). Текстовый
  «👑 x — y 👑» заменить визуальными коронами.
- **C4.** Рука: 4 карты снизу, у каждой капля стоимости с числом; слева превью
  «След.:» следующей карты; кнопка чата 💬 (эмоуты — позже, можно заглушку).
- **C5.** Эликсир: розово-фиолетовая полоса из 10 сегментов, крупное число +
  «Макс.:10»; ×2-подсветка в последнюю минуту.
- **C6.** Недоступные по эликсиру карты — затемнять (есть; проверить контраст).
- **C7.** Над юнитами — мелкая полоса HP + номер уровня.

## D. Механика (паритет)
- Старт 5 эликсира, +1 за ~2.8с, ×2 последние 60с, кап 10 (есть — проверить
  отображение).
- Раунд 4:00, без ничьих (есть) — корректный отсчёт «Осталось».
- Цикл колоды 4+1 (есть).
- Клиент шлёт только намерения авторитетному серверу (есть); невалидный деплой не
  списывает эликсир ни в превью, ни на сервере.
- Хаптик: при установке (есть, light), при падении башни и в конце боя.

## E. Definition of done
- На телефоне в Telegram карта перетаскивается из руки на свою половину и встаёт;
  вертикальный свайп не сворачивает апп.
- Тап-тап тоже работает (десктоп/браузер).
- Невалидный сброс не тратит эликсир; зоны подсвечиваются; ghost-превью видно.
- Башни/таймер/эликсир/счёт-короны выглядят как на референсе.
- `npm test` (28+) и сборка клиента зелёные; добавлен тест на общий хелпер
  валидации зоны (один для клиента и сервера).
